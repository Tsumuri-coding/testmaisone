# Maison 3D

Rendu 3D interactif d'un projet de maison, d'après des plans d'exécution provisoires.
Les documents contractuels prévalent sur toute représentation graphique.

- `index.html` : page autonome (Three.js chargé depuis un CDN, aucune étape de build).
- Vues, coupe, cuisine, sols, portes intérieures (teintes et couleur libre), soleil selon l'heure et la date.
